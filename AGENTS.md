# Agent instructions

This repo is a fork of `JosiahHands/nimPage`. Cloudflare deploys the live site from `main` in `JosiahHands/nimPage`, not from this fork.

## Pull requests

When you edit this repo and are asked to "make a pull request", open it from this fork into `JosiahHands/nimPage`, with base `main`:

```sh
gh pr create -R JosiahHands/nimPage --base main --head Wardcode-frame:<branch>
```

Do not merge it. The owner reviews and merges every pull request.
